I build AI agents that run real business operations in production — and the guardrails that keep them honest.

## 🐾 Patagon

B2B SaaS where AI agents manage day-to-day SMB operations through WhatsApp: inventory and stock alerts, fleet tracking, meeting coordination, reminders, image/document analysis and audio transcription.

- 15+ agent instances across construction, logistics, auto workshops and more
- Deterministic code paths so agents never claim actions they didn't complete
- Idempotent scheduled jobs, human escalation, token-protected REST API

## 🚀 Open source

**[grounded-rag](https://github.com/Sr-Stark08/grounded-rag)** — RAG over company documents that answers with citations or refuses when there is no evidence. Hybrid BM25 + vector search (sqlite-vec), hallucination guardrails, FastAPI, and retrieval evals as a CI quality gate.

**[patagon-inventory-mcp](https://github.com/Sr-Stark08/patagon-inventory-mcp)** — MCP server for conversational inventory management. Idempotent stock movements, tools/resources/prompts, 13 tests, Docker and CI on Node 22/24.

**[n8n-inventory-triage](https://github.com/Sr-Stark08/n8n-inventory-triage)** — n8n + Claude workflow that turns WhatsApp messages into inventory actions. Guardrails so the model can't invent quantities or products, idempotency and human escalation.
